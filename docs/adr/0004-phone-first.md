# 0004 Phone control is a flagship feature

**Status:** Accepted

**Context:** Most screen time is on phones.

**Decision:** Capture, approve, pause or stop, agenda, chat and budgets must work on the phone. Order: email-to-self, PWA, then React Native. Core can run on the desktop or as an opt-in managed cloud instance; both are offered. The phone talks through an end-to-end encrypted relay.

**Consequences:** Event sync format is defined in step 01. Push messages carry no sensitive content. Details: docs/TECHNICAL-DESIGN.md sections 2 and 7.
