OPEN SOURCE BOUNDARY
====================

The NomadNetOps project is distributed under Apache-2.0 license, but only the
following components are open source:

OPEN SOURCE (Apache-2.0):
- Runtime engine (packages/core)
- Policy engine (packages/policy)
- Encryption/crypto (packages/crypto)
- UI components (packages/ui)
- Desktop app shell (apps/desktop)
- Phone app shell (apps/phone)
- Relay server (apps/relay)

CLOSED SOURCE (Proprietary):
- Cloud hosting infrastructure
- Multi-tenant SaaS platform
- Team collaboration features
- Billing and payment processing
- Analytics and telemetry services
- Mobile app stores (iOS/Android distribution)

Users can run the open source components locally for free. Cloud hosting
and team features require a paid subscription.

For more information, see https://nomadnetops.com
